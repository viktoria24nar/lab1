Лабораторная работа №1 — Первичное исследование и оценка качества данных

Описание

Анализ датасета розничных заказов интернет-магазина SuperStore за 2011–2014 гг.
Выполнены: постановка задачи, паспорт датасета, аудит качества данных
(пропуски, дубликаты, аномалии, выбросы) и разведочный анализ с визуализациями.
