## Как запустить

**Через Google Colab (рекомендуется):**

1. Открой `notebooks/01_data_understanding.ipynb`.
2. Меню **Runtime → Run all**.
3. Ноутбук скачает датасет с Google Drive автоматически и выполнит
   все ячейки.

**Локально (Jupyter):**

```bash
pip install pandas numpy matplotlib seaborn gdown jupyter
jupyter notebook notebooks/01_data_understanding.ipynb
```
