Отчёт о качестве данных

**Лабораторная работа №1 «Первичное исследование и оценка качества данных»**
**Датасет:** SuperStore Orders (розничные заказы интернет-магазина)
**Автор:** Нарайкина Виктория студентка 305 группы "Статистика"

1. Введение

В рамках лабораторной работы был проанализирован датасет розничных заказов
интернет-магазина SuperStore за период 2011–2014 гг. Каждая строка
датасета представляет собой одну позицию заказа и содержит информацию о клиенте,
его сегменте, категории товара, датах оформления и отгрузки, объёме продаж,
количестве единиц, скидке, прибыли, стоимости доставки и приоритете заказа.
Общий объём — **51 290 строк и 12 признаков**, среди которых есть числовые,
категориальные и временные.

**Условный заказчик анализа** — отдел продаж и маркетинга компании, а также
руководство, заинтересованное в оценке эффективности ассортимента, ценовой
политики и логистики. Датасет позволяет принимать решения о том, какие
категории товаров продвигать, какие скидки допустимы, а какие ведут к убыткам.

**Задачи интеллектуального анализа данных (ИАД), которые можно решать
на основе этого датасета:**

1. **Сегментация клиентов** по объёму и прибыльности заказов — выделение групп
   клиентов (Consumer, Corporate, Home Office) с разными профилями покупок.
2. **Поиск аномалий** — выявление убыточных заказов, сделок с аномально
   высокой скидкой или подозрительно низкой/высокой прибылью.
3. **Описательная аналитика** — определение категорий товаров и уровней
   приоритета, приносящих наибольшую прибыль.
4. **Прогнозирование прибыли** по параметрам заказа (категория, скидка,
   сегмент, приоритет) — построение регрессионных моделей.

2. Паспорт датасета

| Параметр | Значение |
|----------|----------|
| Количество строк | 51 290 |
| Количество столбцов | 12 |
| Числовые признаки | `sales`, `quantity`, `discount`, `profit`, `shipping_cost` |
| Категориальные признаки | `order_id`, `customer_name`, `segment`, `category`, `order_priority` |
| Временные признаки | `order_date`, `ship_date` |
| Период данных | 2011-01-01 — 2014-12-31 |

**Особенности структуры:**
- Столбец `order_id` содержит меньше уникальных значений (25 035), чем строк
  (51 290). Это означает, что один заказ включает несколько позиций — данные
  имеют иерархическую структуру «заказ → позиции».
- Даты изначально хранились как строки и были преобразованы в тип
  `datetime64[ns]`; пропусков при этом не возникло.
- Все категориальные признаки содержат только ожидаемые значения, без
  опечаток, разного регистра и лишних пробелов.
